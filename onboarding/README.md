# تور آموزشی اولیه (onboarding)

فایل `onboarding.json` در همین پوشه، توضیح دکمه‌های برنامهٔ «دبیره ایرانی» است.
این فایل **داخل برنامه نیست**؛ کاربر در «منوی اصلی ← تور آموزشی اولیه» آن را دانلود می‌کند.
تا دانلود نشود، تور غیرفعال می‌ماند. بعد از دانلود، با لمس هر دکمه‌ای که در این فایل پیام دارد،
پیام همان دکمه (پیش‌فرض ۵ ثانیه) نشان داده می‌شود.

## افزودن تور برای یک دکمه

در آرایهٔ `tours` یک بلوک تازه اضافه کنید. فقط «نام آیتم» و «متن» لازم است:

```json
{ "item": "nav_text_settings", "text": "متن راهنما اینجا" }
```

| فیلد    | لازم؟ | توضیح |
|---------|-------|-------|
| `item`  | بله   | نام آیتم: نام منبع (`nav_text_settings` یا فقط `text_settings`) **یا** همان عنوانی که در منو دیده می‌شود (مثل `تنظیمات متن`) |
| `text`  | بله   | متن پیام (حداکثر ۱۰۰۰ نویسه؛ کوتاه بهتر است، متن‌های بلند در کارت اسکرول می‌شوند). `\n` یعنی خط جدید |
| `title` | خیر   | عنوان کارت؛ نباشد، عنوان آیتم در منو استفاده می‌شود |
| `icon`  | خیر   | یک ایموجی برای نشان کارت (پیش‌فرض 💡) |
| `enabled` | خیر | `false` یعنی این پیام فعلاً نشان داده نشود |

بالای فایل:

- `version`: شمارهٔ نسخه (عدد صحیح). **هر بار فایل را تغییر دادید یکی زیادش کنید** تا برنامه «نسخهٔ جدید» را تشخیص بدهد.
- `updated`: تاریخ دلخواه برای نمایش. `notes`: یادداشت تغییرات که هنگام بروزرسانی نشان داده می‌شود.

## نام آیتم‌ها

- دکمه‌های منوی اصلی: نام‌های `nav_...` در `res/menu/drawer_menu.xml`.
- دکمه‌های صفحهٔ تور: `onboarding_enable`, `onboarding_download`, `onboarding_update`, `onboarding_check`,
  `onboarding_delete`, `onboarding_duration`, `onboarding_count`, `onboarding_position`, `onboarding_progress`,
  `onboarding_autocheck`, `onboarding_effects`, `onboarding_textstyle`, `onboarding_edit`, `onboarding_add`, `onboarding_preview`, `onboarding_reset`, `onboarding_reset_edits`.
- آیتم تازه‌ای که در برنامه به منو اضافه شود، همین که نامش را اینجا بنویسید پیام دارد (بدون نیاز به تغییر کد).

نکته: اگر نام آیتم در برنامه پیدا نشود، پیام بی‌صدا نادیده گرفته می‌شود و مشکلی ایجاد نمی‌کند.
